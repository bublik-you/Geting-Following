# Сила инфографики и презентаций

Восемь интерактивных сцен на TypeScript, Vite, SVG и Canvas 2D. Сборка и офлайн-кэш второй презентации независимы от «4 кота». GitHub Pages объединяет обе сборки после подтверждённого изменения основной ветки.

## Запуск

Из корня репозитория с Node.js 24.

```sh
npm --prefix presentation-2 ci
npm --prefix presentation-2 run dev
```

На GitHub Pages открывайте вторую презентацию по адресу `https://bublik-you.github.io/Geting-Following/presentation-2/`. Адрес папки учитывает обработку вложенных `index.html` уже установленным service worker «4 кота».

## Режим выступления

Нажмите «Начать выступление», чтобы запустить отсчёт. Стрелки меняют сцену, R начинает текущую сцену заново, F включает полноэкранный режим, M переключает звук. Панель «Сцены» позволяет сразу перейти к нужной демонстрации. «Заметки» открываются в отдельной вкладке и показывают синхронизированный текст, план сцены и время. Таймер вручную управляется докладчиком. Действия и план на 7:00 описаны в [MONOLOG.md](MONOLOG.md).

Положение колонок, масштаб карты, пары, граница графика и прогресс очистки сохраняются при переходах в пределах сеанса. «Начать выступление» начинает новый сеанс. Сложные жесты дублируются кнопками или клавишами. Кнопка «Пропустить действие» доступна перед финалом.

## Редактирование

- `src/content.ts` хранит заголовки, длительность, подсказки и речь. При изменении речи обновите `MONOLOG.md`.
- `src/scenes/` содержит модули сцен. Регистрируйте их в `src/scenes/index.ts` в том же порядке, что и план. Каждый модуль объявляет начальное состояние и отрисовку через `scene(initial, mount)`. Для обработчиков и отложенных действий используйте сигнал текущей сцены.
- `src/style.css` задаёт оболочку, цвета и типографику. Правила отдельных сцен находятся в `src/scenes.css`.
- Кладите локальные ресурсы в `public/` или импортируйте из `src/`. Сборщик автоматически включает их в кэш. Для `public/` используйте путь от `import.meta.env.BASE_URL`. Перед добавлением медиа проверьте вес, особенно для мобильного офлайна.
- [SOURCES.md](SOURCES.md) описывает научную основу, условные примеры и лицензии.

## Сборка и проверки

Из корня, после установки обоих наборов зависимостей.

```sh
npm run build
npm --prefix presentation-2 run build
npm --prefix presentation-2 run assemble:pages
npm --prefix presentation-2 run test:pages
npm --prefix presentation-2 run package:offline
```

Итоговая сборка Pages находится в `presentation-2/pages-dist/`. Пакет готовых файлов для локального сервера создаётся в `presentation-2/offline/`. Инструкция для планшета находится в [PLAY_OFFLINE.md](PLAY_OFFLINE.md).
