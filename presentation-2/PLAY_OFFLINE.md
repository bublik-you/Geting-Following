# Офлайн-показ на Android

## Установка с HTTPS

1. На планшете откройте адрес презентации в Chrome. Для GitHub Pages используйте адрес с завершающим слешем `/Geting-Following/presentation-2/`.
2. Дождитесь отметки «Готово офлайн». При наличии пункта «Установить приложение» добавьте презентацию на главный экран. Иначе сохраните точный URL в закладках.
3. Включите режим полёта, выключите Wi-Fi, закройте вкладку и откройте презентацию снова.
4. Пройдите восемь сцен. Проверьте масштабирование двумя пальцами, перетаскивание колонок и веник. Включите звук кнопкой в шапке, чтобы браузер разрешил встроенные сигналы.
5. Подключите проектор, поверните планшет горизонтально и выберите полноэкранный режим. Запустите «Начать выступление». Таймер показывает прошедшее время и лимит 7:00. Заметки можно открыть в отдельной вкладке.

Храните кэш браузера до показа. После обновления откройте страницу онлайн и ещё раз проверьте её в режиме полёта.

## Запуск напрямую из файла

Скачайте артефакт `infographics-html` из GitHub Actions, распакуйте его и откройте `infographics.html` в браузере. Внутри файла уже находятся все восемь сцен, шрифты и интерактивность. Сайт, интернет и локальный сервер для этого способа не нужны.

На Android открывайте файл из менеджера файлов через браузер. Некоторые встроенные просмотрщики документов показывают только разметку и блокируют сценарии. Открытие проверено в Chromium по `file://`.

## Резервный ZIP с серверной сборкой

В `infographics-offline.zip` лежат самостоятельный HTML, готовая сборка с офлайн-кэшем, монолог и источники. Для запуска серверной сборки используйте следующие шаги.

Если на Android заранее установлен Termux с Python, откройте папку архива и запустите локальный сервер.

```sh
python -m http.server 8080 --bind 127.0.0.1
```

На компьютере вместо `python` может понадобиться `python3`. Затем откройте `http://127.0.0.1:8080/` на том же устройстве. Локальный сервер работает в режиме полёта. В архиве также лежат монолог и источники.

Сенсорные действия доступны через жесты и кнопки. На физическом планшете до выступления проверьте работу браузера, звука и подключения к проектору.
