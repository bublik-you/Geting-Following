# Как показать «4 кота» без интернета на Android

## GitHub Pages и офлайн-кэш

1. Откройте финальную ссылку GitHub Pages в обычной вкладке Chrome с интернетом. Для этой ветки публикация появится после её отдельного утверждения и объединения.
2. Дождитесь отметки «Готово офлайн». При наличии команды «Установить приложение» в меню Chrome можно добавить его на главный экран. Закладка на точный URL тоже подходит.
3. Включите режим полёта и убедитесь, что Wi-Fi выключен. Закройте вкладку и снова откройте страницу по закладке или через значок установленного приложения.
4. Нажмите «Начать защиту». Нажатие разблокирует звук в браузере. Проверьте обе точки, карточки команды, «Метрики», заметки и приложения. «Разделы» позволяют быстро перейти к нужной сцене.
5. Подключите проектор и проверьте полноэкранный режим. Сохраните вкладку или закладку и не очищайте данные сайта до выступления. Chrome может удалить кэш при нехватке места. После обновления версии снова откройте её онлайн и дождитесь отметки.

## ZIP и отдельный HTML

1. Скачайте артефакт офлайн-сборки из GitHub Actions и распакуйте `four-cats-offline.zip` на планшете заранее. Внутри есть `presentation.html`, PDF, источники и монолог.
2. Откройте `presentation.html` в браузере через файловый менеджер. Выберите Chrome или другой браузер, который открывает локальный HTML со скриптами. Просмотрщики документов иногда показывают снимок страницы без работающих кнопок.
3. Включите режим полёта и откройте файл повторно. HTML содержит код, оформление, изображения и приложения с локальными вложениями. Звуки синтезируются браузером после нажатия. При открытии заметок или резюме браузер может создавать отдельную вкладку.
4. Если файловый менеджер открывает HTML только в упрощённом просмотрщике или через несовместимый `content://`, запустите заранее проверенную версию GitHub Pages из кэша. В архиве также лежит PDF с кратким резюме.

Проверены HTTPS и офлайн-перезапуск в Chromium, а также открытие отдельного HTML через `file://` с отключённой сетью. Эти браузерные проверки не заменяют прогон на вашем Android-планшете с проектором.
