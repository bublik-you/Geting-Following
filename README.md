# 4 кота — Бизнес-разведка

Интерактивная презентация о Burger King и «Молочае» в Новосибирске. Карта района метро «Студенческая» объединяет 13 сцен. В презентации доступны полевые записи от 15 и 18 ноября 2026 года, сопоставленные заказы и пилотные гипотезы.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Откройте адрес с путём `/Geting-Following/`, который выводит Vite.

Для репетиции и проверки используйте production-сборку.

```sh
npm run build
npm run preview
```

Откройте `http://localhost:4173/Geting-Following/`. Для планшета в той же локальной сети используйте IP-адрес компьютера вместо `localhost`. Для проектора откройте презентацию в альбомной ориентации и нажмите значок полноэкранного режима. На HTTPS и localhost браузер сохраняет production-сборку и материалы для повторного запуска без сети после первой успешной загрузки.

## Управление

- На карте перетащите фон для перемещения. Используйте колесо, две точки касания или кнопки для масштаба. Кнопка ⌖ возвращает общий план.
- Наведите курсор на здание или метку заведения, чтобы увидеть превью. На сенсорном экране нажмите точку один раз и затем нажмите окно превью. Касание свободной части карты закрывает окно. Метки участников сразу открывают знакомство.
- «Начать защиту» запускает отсчёт с планом ровно на 07:00. Главы переключаются вручную стрелками и кнопками. Таймер продолжает идти после 07:00 и выделяется цветом.
- «Разделы» доступны в обоих режимах. Флажок «Перейти без анимации» действует для переходов из списка. Нажмите «Заметки», чтобы открыть текущую реплику и план в отдельной вкладке. Перенесите вкладку на экран докладчика. Синхронизация работает в том же браузере и профиле.
- «Приложения» открывают материалы и медиатеку. Печатное резюме находится в меню разделов и открывается по адресу `/Geting-Following/?mode=summary`.

## Проверка и GitHub Pages

```sh
npm run build
npx playwright install chromium
npm test
npm run package:offline
```

Локально Playwright использует Chromium из `/usr/bin/chromium`. Для другого пути задайте `CHROMIUM_PATH`. В CI используется Chromium, установленный Playwright.

Локальные тесты поднимают HTTPS с временным сертификатом OpenSSL. Workflow собирает и проверяет проект на pull request. ZIP с отдельным HTML и PDF доступен в артефактах запуска. Инструкция для планшета находится в [PLAY_OFFLINE.md](PLAY_OFFLINE.md). GitHub Pages публикуется при обновлении `main` или ручном запуске workflow с ветки `main`. Файлы сборки находятся в `dist/`. Путь размещения задан в `vite.config.ts`.
